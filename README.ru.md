# Voice Replay PRO

> Записывает звук из твоих наушников (например, войс-чат игры) и воспроизводит его в виртуальный микрофон одной горячей клавишей.

**Автор:** [LubitielDela](https://github.com/LubitielDela) · **Лицензия:** [MIT](LICENSE) · **Платформа:** Windows 10/11

Voice Replay PRO записывает всё, что звучит в твоих наушниках, и воспроизводит запись в виртуальный микрофон (VB-Cable). Игра, Discord или любое другое приложение слышат её как обычную речь с твоего микрофона. Подходит для пранков с друзьями, саундборда и тестов голосового чата.

## Возможности

- Запись и воспроизведение одной кнопкой (переключатели старт/стоп)
- Меню с настройками, открывается горячей клавишей
- Оверлей поверх всех окон: статус (запись, воспроизведение, ожидание), выбранная запись, список клавиш
- Оверлей можно перетаскивать мышью или ставить в любой угол экрана
- Все горячие клавиши меняются в меню
- Список записей: воспроизведение, переименование, удаление
- Выбор устройства записи и устройства вывода, громкость, прослушивание в своих наушниках
- Настройки сохраняются автоматически

## Этика и правила

- Записывай и воспроизводи голос человека, только если он согласен. Используй программу для шуток с друзьями, а не для обмана, травли или выдачи себя за другого человека.
- Во многих играх и на многих серверах такое использование запрещено правилами. Ответственность за возможные баны лежит на тебе.
- Записи (`clips/`) могут содержать чужие голоса. Не публикуй их (папка уже добавлена в `.gitignore`).

## Требования

- Windows 10 или 11
- [Python 3.9+](https://www.python.org/downloads/) (при установке поставь галочку **Add Python to PATH**)
- [VB-Cable](https://vb-audio.com/Cable/) (бесплатный виртуальный аудиокабель)

## Установка

1. Скачай репозиторий (**Code → Download ZIP**) и распакуй в любую папку.
2. Установи VB-Cable:
   1. Распакуй архив VB-Cable.
   2. Нажми правой кнопкой на `VBCABLE_Setup_x64.exe` и выбери «Запуск от имени администратора».
   3. Нажми **Install Driver** и перезагрузи компьютер.
3. Установи зависимости. Открой командную строку в папке проекта и выполни:
   ```
   pip install -r requirements.txt
   ```

## Настройка звука

После установки VB-Cable в Windows появятся два устройства: **CABLE Input** (вывод) и **CABLE Output** (ввод).

1. **Параметры звука → Вывод:** выбери свои наушники как устройство по умолчанию. Программа записывает именно то, что звучит в них.
2. **Параметры звука → Ввод:** выбери **CABLE Output** как микрофон по умолчанию.
3. В самой игре (или Discord) выбери микрофон **CABLE Output** или «По умолчанию».
4. В «Панель управления → Звук → Воспроизведение» у наушников должно стоять и «Использовать по умолчанию», и «Использовать устройство связи по умолчанию».

### Чтобы тебя слышали и когда ты говоришь сам

Так как микрофоном в играх стал кабель, твой настоящий микрофон нужно подмешать в него:

1. «Панель управления → Звук → Запись».
2. Двойной щелчок по твоему настоящему микрофону → вкладка «Прослушать».
3. Включи «Прослушивать с данного устройства», выбери **CABLE Input** и нажми «Применить».

## Запуск

Запускай **от имени администратора**, иначе горячие клавиши в играх могут не работать.

Самый простой способ: двойной клик по `start.bat`. Он сам запросит права администратора и запустит программу в свёрнутом окне.

Вручную:
```
python voice_replay_pro.py
```

Подключай Bluetooth-наушники **до запуска** программы. Если сменил наушники во время работы, перезапусти её или выбери устройство в настройках.

## Как пользоваться

Горячие клавиши по умолчанию:

| Клавиша | Действие |
|---------|----------|
| F8 | Начать / остановить запись |
| F9 | Воспроизвести / остановить |
| F10 | Предыдущая запись |
| F11 | Следующая запись |
| INSERT | Открыть / скрыть меню |
| F7 | Показать / скрыть оверлей |

Типичный сценарий:

1. Кто-то говорит в войс-чате. Нажми **F8**, чтобы начать запись.
2. Нажми **F8** ещё раз, чтобы остановить. Запись сохранится в папку `clips`.
3. Нажми **F9**, и запись воспроизведётся в твой виртуальный микрофон. Повторное нажатие F9 останавливает воспроизведение.
4. Если в игре микрофон включается по кнопке, держи эту кнопку во время воспроизведения.

Записи длиннее 120 секунд останавливаются и сохраняются автоматически.

## Меню

Открывается клавишей INSERT (можно изменить).

- **Записи:** список записей, кнопки записи и воспроизведения, переименование, удаление, открытие папки. Двойной клик по записи воспроизводит её.
- **Горячие клавиши:** нажми на кнопку нужного действия и затем на новую клавишу или комбинацию (например, `ctrl+f5`).
- **Настройки:** устройства, громкость, прослушивание в своих наушниках, оверлей (включить, прозрачность, положение, поверх всех окон), меню поверх всех окон.

## Оверлей

Маленькое окно со статусом и подсказками клавиш. Положение можно менять мышью или кнопками ↖ ↗ ↙ ↘ в настройках.

Оверлей виден поверх игры только в **оконном или безрамочном режиме** («Полноэкранный режим в окне»). В полноэкранном эксклюзивном режиме Windows его скроет.

## Решение проблем

| Проблема | Что делать |
|----------|-----------|
| Окно сразу закрывается | Запусти из командной строки (`python voice_replay_pro.py`) и посмотри текст ошибки. |
| `ModuleNotFoundError` | Выполни `pip install -r requirements.txt`. |
| Ошибка про `fromstring` или `binary mode` | Выполни `pip install "numpy<2"`. |
| Не найдено устройство CABLE Input | Проверь установку VB-Cable и перезагрузи компьютер. Устройство вывода можно выбрать вручную в настройках. |
| Горячие клавиши не работают | Запусти от имени администратора. |
| Записывается тишина | Проверь, что наушники стоят устройством вывода по умолчанию, или выбери устройство в настройках. |
| В игре меня не слышно | Проверь, что микрофоном выбран CABLE Output, и настрой подмешивание настоящего микрофона (см. выше). |
| Оверлея не видно в игре | Переключи игру в оконный или безрамочный режим. |
